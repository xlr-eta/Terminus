# obsidian/

Snapshots and source files of Chris's Obsidian PKM system.

| Folder | Contents |
|---|---|
| `settings/` | Vault `.json` config snapshots (`.obsidian/*.json`) |
| `templates/` | Templater & core templates |
| `snippets/` | CSS snippets / theme customisation |
| `plugins/` | Community plugin configs and usage notes |
| `vault-structure.md` | Folder map and taxonomy of the live vault |

**Why:** the vault itself lives on Chris's machine; this folder keeps a versioned copy of the *system* (config, templates, styling) so it can be rebuilt or rolled back.
